# Código de conducta

Este proyecto debe ser un espacio seguro para personas con distintas formas de
comunicarse. Se respetarán los tiempos, apoyos, tecnologías, lenguajes e
identidades elegidos por cada persona.

No se toleran discriminación, capacitismo, hostigamiento, revelación de datos
personales ni cuestionamientos sobre la legitimidad de una forma de
comunicación. Toda decisión que afecte a personas con discapacidad debe buscar
su participación significativa.
