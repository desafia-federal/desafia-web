# Seguridad

No publiques vulnerabilidades en un issue abierto. Informalas de manera
privada a `seguridad@desafiafederal.org` cuando esa casilla esté habilitada.

El portal no debe almacenar datos de tarjetas. Las donaciones se procesan en
plataformas externas verificadas y los formularios solo recolectan la
información imprescindible para responder el contacto.
